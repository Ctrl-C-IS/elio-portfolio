# Elio Melhem – Portfolio

Node.js + Express static portfolio.

## Run locally
    npm install
    npm start        # http://localhost:3000

## Deploy on Hostinger (Node.js Web App)
1. hPanel → Websites → Add website → Node.js Apps.
2. Upload this folder as a ZIP (or connect GitHub). Do NOT include node_modules.
3. Framework: Express.js · Entry file: server.js · Node 18+ · Start command: npm start
4. Hostinger runs npm install and sets PORT automatically.
